# 🔒 Repository Notice

Privacy Notice: For privacy and security purposes, this public repository does not contain the full application source code. Instead, it hosts the preliminary, original base programs and scripts that served as the foundation for the platform.

The complete, production-ready codebase for Panacor Web—including the React frontend, Express backend, and Python AI engines—is securely maintained in a separate, private repository.

Overview of Platform Features
While the full source code is kept private, the Panacor Web platform includes the following capabilities:

## Automation Tools
Quotation Maker: Automated parsing and generation of quotations from Excel and PDF files using Gemini/Claude.
PDF to Excel: Structured data extraction with advanced heading detection.
Legends Maker: Automated image cropping and OCR (via Tesseract/EasyOCR) to extract legends from drawings.
O&M Manual Builder: Automated search, download, and merging of Operations & Maintenance manuals into a unified PDF.

## AI Hub
Knowledge Bases: User-specific document collections backed by ChromaDB for processing PDF, DOCX, TXT, and MD files.
Document Chat: Hybrid RAG implementation with streaming answers and inline citations for querying manuals and company data.
AI Search: Deep research tool integrating multiple search engines (Google, Bing, Reddit) for comprehensive automated research and synthesis.
Core Platform
Secure JWT authentication and role-based access control (Admin vs. Standard User).
Real-time job history and queuing system.
Modern, responsive UI with light/dark theme support.
